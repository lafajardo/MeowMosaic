## Getting Started
Run the command ```cd backend``` and ```npm install``` from your terminal. Repeat for the frontend directory. This will install the necessary dependencies for the ExpressJS and AngularJS project.

Create a file in the ```backend``` directory called ```.env```. This will hold all of the environment variables necessary for running the project in development and production. Inside the file, copy and paste the following:
```
PORT=3000
```

To start the express backend locally, ```cd backend``` and run the command ```npx ts-node src/index.t```.

To start the angular frontend locally, ```cd frontend``` and run the command ```ng serve```
